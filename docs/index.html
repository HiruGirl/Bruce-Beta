Bruce Light — CYD-2432S028

WiFi + BLE + JS Interpreter + Clock/Others — a trimmed, lighter build for the classic 2.8" CYD touch display.

Important: the browser can only flash a real firmware image if it exists. The Light build is produced from this repository (env CYD-2432S028-JSLITE); see docs/README.md. If you just want a working Bruce on a CYD without the light build, the upstream release is linked at the bottom of this page.

Instructions

  1. Hook your CYD-2432S028 up over USB.
  2. Press Connect and pick the COM port.
  3. Press Flash. Do not unplug the board while it's flashing.
  4. Boot — Bruce Light will land on the main menu with WiFi, BLE, JS Interpreter and Clock/Others.

Not included (the point of the trim)

    
No RF/SubGHz, NRF24, IR, RFID, GPS, LoRa, FM, Ethernet, SDR, packet sniffers, DoS/evil-twin attack menus (Listen TCP / SOCKS4 / Telnet / SSH / NetCut / Responder / Scan Hosts / Channel Analyzer / Jam Detect / WiFite), BadUSB/HID submenus, microphone, iButton, or the Launcher-only metadata. Wifi and JS interpreter menus for those features are hidden entirely.
